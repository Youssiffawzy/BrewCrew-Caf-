# BrewCrew-Caf-
This is a freelance project for BrewCrew Café
# Objective:
Analyze sales patterns across seasons to optimize product offerings and maximize profitability.

Tools Used:

•	Python (Data Analysis and Visualization)

•	Tableau (Interactive Visualization)

•	Data Source: "BrewCrew Café Dataset.xlsx"

________________________________________
# Methodology:
•	Analyzed seasonal trends across product categories

•	Calculated profit margins by season and channel

•	Created visualizations for pattern identification

•	Performed channel-specific analysis
________________________________________
# 📊 Key Insights:
•	Seasonal Performance

* Spring: Highest profitability (36.98% margin for Espresso).
  
* Summer: Strong Cold Brew performance (36.07% margin)
  
* Autumn: Consistent Pastries performance
  
* Winter: Stable across categories
  
•	Wholesale vs Direct Customer Analysis

- Wholesale Channel

* Highest margins in Spring (Espresso: 36.98%, Pastries: 36.46%)

* Consistent performance in bulk orders

* Strong institutional relationships

- Direct Sales Channel

* Peak performance in Summer (Cold Brew: 36.07%)
  
* Higher transaction frequency

* Seasonal sensitivity

•	Product Portfolio Optimization

Top Performing Combinations:

1. Espresso (Spring, Wholesale): 36.98% margin

2. Pastries (Spring, Wholesale): 36.46% margin

3. Cold Brew (Summer, Direct): 36.07% margin

4. Pastries (Autumn, Wholesale): 35.79% margin

5. Pastries (Summer, Direct): 35.48% margin

# 📌 Recommendations:
